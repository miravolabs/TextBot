---

## ✨ Features

- **High-Volume Repetition:** Multiply any custom message up to 10,000 times instantly without UI freezes.
- **Custom Numbering Styles:** Format your generated text with None, Left (Prefix), or Right (Suffix) indexes.
- **One-Tap Clipboard Copy:** Fast clipboard integration with haptic feedback.
- **Ultra Lightweight:** Sub-3 MB APK size (~2.5 MB) achieved with R8 minification and zero bloatware.
- **Pure Material Design 3:** Modern, adaptive layout crafted exclusively with Jetpack Compose.

## 🛠️ Tech Stack & Architecture

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Declarative UI)
- **Design System:** Material You / Material Design 3
- **State Management:** Compose State API & Architecture Components
- **Minification:** R8 ProGuard Optimization
- **Minimum SDK:** API 23 (Android 6.0+)
- **Target SDK:** API 37 (Android 17)
